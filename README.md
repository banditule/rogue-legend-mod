# Rogue Legend — Modded by Banditu

Mod no oficial para **iOS (IPA)** con un panel flotante que permite activar y ajustar distintas funciones durante el juego.

## Funciones

- **Daño ajustable:** multiplicador de ×1 a ×100.
- **Velocidad ajustable:** multiplicador de ×1 a ×10.
- **Modo dios:** evita el daño recibido.
- **Beneficios VIP y sin anuncios:** activa los beneficios locales implementados en el mod.
- **Panel simplificado:** botón flotante `B`, desplazable por la pantalla, sin publicidad ni enlaces promocionales.

## Run automática

La automatización puede activarse desde:

- La pantalla principal.
- El Desafío de Estrellas.
- Una partida compatible ya iniciada.

### Funcionamiento

- Accede automáticamente al Desafío de Estrellas desde la pantalla principal.
- Selecciona el último capítulo ya superado disponible en el modo elegido: **Normal** o **Élite**.
- En modo Élite, establece la recompensa ×3 antes de comenzar.
- Automatiza tiradas, selección de cartas, decisiones de ruta y eventos compatibles.
- Sale de las tiendas sin realizar compras.
- Cierra avisos de modificadores y pantallas de resultados.
- Repite las partidas mientras haya suficiente energía.
- Se detiene si:
  - se cancela manualmente;
  - se agota la energía;
  - se encuentra un error que impide continuar.


Las versiones futuras del juego pueden requerir actualizar o adaptar el mod.

## Instalación

### iOS

Descarga el archivo `.ipa` desde la sección **Releases**.

El IPA se distribuye sin firmar y requiere firma e instalación mediante una herramienta compatible, como **Sideloadly**.
